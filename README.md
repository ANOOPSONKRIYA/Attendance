# Class Attendance Web App

A modern, fully-responsive web app for classroom attendance management.

## 🚀 Features

- ✅ **Live present/absent counter (updates instantly)**
- ✅ **Sticky header with search/filter** (by roll or name)
- ✅ **Better button layout (grouped neatly)**
- ✅ **Responsive list height** (adapts to screen size)
- ✅ **Smooth animations on items**
- ✅ **Prints both Present + Absent with totals in output**
- 🌙 **Dark/Light mode toggle** (retains your setting)
- 📱 **Fully responsive design** — mobile, tablet & desktop
- ✨ **Modern SVG and Font Awesome social icons**
- 🧩 **Easy JSON import/export** for students

## 📂 Project Structure
- `index.html` – Main UI
- `style.css` – All styles (responsive, themed)
- `script.js` – App logic (attendance, search, output, theming)
- `students.json` – Example/class students data
